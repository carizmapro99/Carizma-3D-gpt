# Carizma Storyboard Studio

وب‌اپ فارسی ثبت استوری‌بورد از صحنهٔ سه‌بعدی. پیش‌فرض پروژه ۶ پنل، نسبت ۹:۱۶ و خروجی مستقل ۱۰۸۰×۱۹۲۰ است.

## استفاده

1. «تنظیم پروژه» را باز کنید و تعداد پنل‌ها، نسبت تصویر و وضوح دلخواه را انتخاب کنید.
2. فایل صحنهٔ `.html` یا `.js` را با «ورود صحنه» باز کنید یا از «کد صحنه» برای چسباندن کد استفاده کنید. برای امتحان برنامه، مدل سادهٔ نانوایی آماده است.
3. پنل را از شبکهٔ پنل‌ها یا منوی زیر نمای سه‌بعدی انتخاب کنید. با کشیدن بچرخید، با چرخ ماوس یا حرکت دو انگشت زوم کنید و با «جابجایی» مرکز دوربین را حرکت دهید. «زاویه دید» میدان دید دوربین را تغییر می‌دهد.
4. «ثبت این نما» یا «ثبت پنل» را بزنید. هر پنل می‌تواند زمان و یادداشت داشته باشد. در صحنه‌های سازگار، «بازگردانی زاویه» دوربین ثبت‌شده را بازیابی می‌کند.
5. هر پنل را با PNG جداگانه دانلود کنید، همه را به‌صورت ZIP بگیرید یا تعداد ستون‌ها، شماره و زمان و جای پنل‌های خالی را برای شیت تنظیم کنید. شیت برای سازگاری با مرورگرهای موبایل تا ۴۰۹۶ پیکسل در هر ضلع محدود می‌شود. PNG تکی با وضوح انتخاب‌شده ثبت می‌شود.

پروژه در همان مرورگر ذخیره می‌شود. برای انتقال به مرورگر یا دستگاه دیگر، «پشتیبان پروژه» را دانلود کنید. فایل JSON شامل کد صحنه، تنظیمات، تصاویر و زاویه‌های ثبت‌شده است. برنامه یک پروژهٔ جاری را نگه می‌دارد. پیش از تعویض پروژه می‌توانید از پروژهٔ جاری پشتیبان بگیرید.

## فرمت صحنه

### JavaScript با Three.js

فایل JS را به شکل یک اسکریپت معمولی بنویسید. این محیط نسخهٔ r128 را همراه OrbitControls آماده می‌کند و متغیرهای `THREE`، `scene`، `camera`، `renderer`، `controls` و `studio` را در اختیار کد می‌گذارد.

```js
scene.background = new THREE.Color('#d6b99d');
scene.add(new THREE.HemisphereLight(0xffffff, 0x604034, 2));
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshStandardMaterial({ color: 0xc46a3c })
);
cube.position.y = 0.5;
scene.add(cube);
camera.position.set(3, 2, 4);
controls.target.set(0, .5, 0);
studio.addPreset('نمای نزدیک', [1.3, 1.1, 2], [0, .5, 0], 36);
```

اختیاری: `studio.animate = seconds => { ... }` برای صحنهٔ متحرک. زاویه و عکس ثبت می‌شود. وضعیت متغیرهای دلخواه داخل اسکریپت و زمان انیمیشن در پشتیبان نما ثبت نمی‌شود.

### HTML مستقل

فایل‌های HTML مستقل، از جمله نسخهٔ `Carizma_Bakery.html` که تابع `window.__CARIZMA_CAPTURE__` دارد، در قاب ایزوله اجرا می‌شوند. دو کتابخانهٔ شناخته‌شدهٔ r128 فایل نانوایی به‌صورت داخلی تأمین می‌شوند. برنامه برای همان نسخهٔ نانوایی گزینه‌های دوربین و زاویه‌های آماده را به کنترل‌های خودش وصل می‌کند.

برای HTML دیگر، اتصال پیشنهادی:

- `window.__CARIZMA_CAPTURE__(width, height)` تصویر را به شکل PNG data URL یا `HTMLCanvasElement` برگرداند. تابع می‌تواند async باشد.
- در صورت نبود تابع ثبت، برنامه از نخستین بوم قابل مشاهده استفاده می‌کند. WebGL برای ثبت مستقیم از بوم ممکن است به `preserveDrawingBuffer: true` نیاز داشته باشد. در این حالت وضوح واقعی محدود به وضوح بوم است.
- برای دسترسی به کنترل‌های مشترک، می‌توان API دوربین خود را به شکل `window.__CARIZMA_CAMERA__ = { get, apply, presets }` فراهم کرد. `get()` وضعیت `{ position: [x,y,z], target: [x,y,z], fov, preset }` را برمی‌گرداند. `apply({ kind, value })` فرمان‌های `aspect`، `orbit`، `pan`، `zoom`، `fov`، `preset`، `restore` و `reset` را می‌گیرد و وضعیت تازه را برمی‌گرداند. `zoom` ضریب فاصله، `preset` اندیس آرایه و `restore` وضعیت ذخیره‌شده را می‌گیرد. `presets` آرایهٔ نام‌هاست.

این نسخه اسکریپت مرورگری اجرا می‌کند. فایل‌های Blender و Python و پروژه‌های چندفایلی با مدل‌ها یا تکسچرهای جداگانه باید ابتدا به یک صحنهٔ وب مستقل تبدیل شوند. دارایی‌های صحنه را در HTML یا JS به‌صورت دادهٔ جاسازی‌شده قرار دهید. قاب صحنه دسترسی مستقیم به دادهٔ پروژه ندارد و بارگذاری منابع بیرونی در آن محدود است.

صحنه‌های HTML که رندرر خودشان را می‌سازند به WebGL فعال نیاز دارند. برای صحنه‌های سادهٔ JS برنامه رندر نرم‌افزاری دارد که هندسه و رنگ پایه را نشان می‌دهد. سایه، تکسچر و افکت‌های اختصاصی WebGL در آن بازسازی نمی‌شوند.

## GitHub Pages

1. محتویات ZIP را مستقیم در ریشهٔ یک مخزن GitHub قرار دهید تا `index.html` در ریشه باشد.
2. در مخزن به **Settings → Pages** بروید.
3. در **Build and deployment**، منبع **Deploy from a branch** را انتخاب کنید و روی **main / (root)** ذخیره کنید.
4. پس از انتشار، آدرس را از همان صفحهٔ Pages باز کنید.

پروژه سرور، کلید API یا مرحلهٔ Build ندارد. مسیر فایل‌ها نسبی است و روی Pages زیر مسیر مخزن کار می‌کند. برای تست محلی پس از بازکردن ZIP، در پوشهٔ پروژه `python3 -m http.server 8000` را اجرا کنید و `http://localhost:8000/` را باز کنید.

کتابخانه‌های Third-party همراه با مجوزهایشان در پوشهٔ `vendor` قرار دارند.
